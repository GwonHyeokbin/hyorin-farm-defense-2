# 효린이의 픽셀 모험

농장 방어 게임과 별도로 실행되는 한국어 2D 횡스크롤 플랫폼 액션 게임입니다. 좌우로 이어지는 농장 길을 달리고, 점프해 발판을 건너고, 새총으로 다가오는 동물들을 물리치세요. 제공된 효린 스프라이트 시트에서 분리한 단계별 캐릭터 애니메이션을 사용합니다.

HTML5 Canvas와 Phaser 3로 동작하며 서버나 외부 미디어 요청이 없습니다. 기록·자동 저장·이어하기 코드는 이 게임 전용 브라우저 저장 공간을 사용합니다.

## 실행

Node.js 20 이상과 pnpm 9이 필요합니다.

```powershell
pnpm install
pnpm dev
```

## 조작

- 왼쪽/오른쪽: `A` / `D` 또는 방향키
- 점프: `Space` 또는 위쪽 방향키. 착지 후 다시 점프할 수 있습니다.
- 새총: `J`, `F` 또는 마우스 클릭
- 탄환 선택: 상단 버튼 또는 `1`–`6`
- 일시정지: `Esc`
- 스마트폰: 화면 아래 좌우·점프·공격 버튼. 여러 버튼을 동시에 누를 수 있습니다.

점프 중 동물과 부딪히지 않도록 피하고, 위에서 내려오며 밟아 물리칠 수도 있습니다. 플랫폼에는 실제 착지 판정이 있고 카메라는 효린이를 따라 좌우로 스크롤합니다.

## 성장과 전투

- 2단계 어린이 효린으로 시작합니다. 초코우유를 모으면 청소년과 성인으로 성장합니다.
- 피격되면 한 단계 어려지고, 아기 상태에서 다시 맞으면 목숨이 줄어 출발점에서 재시작합니다.
- BB탄, 강철 BB탄, 돌멩이, 폭렬탄, 번개탄, 메테오탄이 적중 판정과 피해 효과를 갖습니다. 특수 탄환은 구간을 통과할 때 보충됩니다.
- 동물 무리를 물리치면 다음 구간 준비 화면에서 새총과 점프를 강화하거나 동료를 맞이할 수 있습니다.
- 작은 동물, 까마귀, 멧돼지와 다섯 번째 구간의 왕멧돼지가 등장합니다.

## 저장과 배포

게임 상태는 12초 간격과 일시정지·구간 통과 시 자동 저장됩니다. 이어하기 코드는 `HPA1` 접두사와 체크섬을 사용하며 점수, 성장 단계, 목숨, 위치, 초코우유, 탄약과 전투 상태를 담습니다. 이어하기 코드는 서버에 전송되지 않습니다. 농장 방어 게임의 코드 및 LocalStorage 키와 분리되어 있습니다.

정적 빌드와 테스트:

```powershell
pnpm test
pnpm run typecheck
pnpm run build
pnpm run preview
```

GitHub Pages 배포를 위해 폴더의 파일을 별도 저장소 루트에 올리고, GitHub Actions 배포를 선택하세요. Vite가 저장소 하위 경로를 포함해 자산 링크를 생성합니다.

## 시험 범위

자동 테스트는 플랫폼 점프·착지·이동 경계, 성장·피격·목숨, 탄환 효과와 이어하기 코드 복원을 확인합니다. 브라우저 확인과 실제 휴대폰 조작은 빌드 이후 별도로 기록합니다.
